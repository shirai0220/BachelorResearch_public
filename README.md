【主な機能】
1. 実験中、MR空間において実験参加者がどこを見ているのか、それを何秒見ているのかを記録します。
2. 呈示した物体のタイトル音声を流し、実験参加者に思い出してもらったうえでピンチを用いた記憶力のチェックをして、その結果を保存する。

※なお、3Dモデルが容量の関係でpushされていないため、実行はできません。
