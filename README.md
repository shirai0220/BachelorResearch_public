【主な機能】
1. 実験中、MR空間において呈示された物体(実物/仮想物)を覚える時や思い出す時に、実験参加者がどこを見ているのか、それを何秒見ているのかを記録する。
2. ピンチ操作を使用することで、実験参加者が呈示された物体を思い出したか、呈示された物体の特徴に関する文章について真か偽のどちらを選択するかを記録する。
※なお、3Dモデルが容量の関係でpushされていないため、実行はできません。
